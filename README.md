# Customer Segmentation Using Clustering

## Overview

Unsupervised learning project focused on identifying customer segments through clustering techniques.

## Techniques Used

- PCA
- K-Means
- DBSCAN
- Data Standardization

## Objectives

- Reduce dimensionality
- Discover hidden customer groups
- Improve business understanding
- Support customer retention strategies

## Tools

- Python
- Pandas
- Scikit-Learn
- Matplotlib
- Seaborn

## Results

Different customer segments were identified based on demographic and financial characteristics, providing valuable insights for business decision-making.
